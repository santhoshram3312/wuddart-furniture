# Wuddart Furniture — SEO Implementation Checklist

1. **Sitemap**:
   - Location: `https://wuddartfurniture.in/sitemap.xml`
   - Configured in: `public/sitemap.xml` and root `sitemap.xml`

2. **Robots.txt**:
   - Location: `https://wuddartfurniture.in/robots.txt`
   - Configured in: `public/robots.txt` and root `robots.txt`

3. **SEO Metadata in `index.html`**:
   - Title: `Wuddart Furniture | Teakwood Furniture in Uthukuli, Tirupur`
   - Meta description with local keywords (Uthukuli, Tirupur, Kerala Teakwood).
   - Canonical URL: `https://wuddartfurniture.in/`
   - OpenGraph tags for WhatsApp, Facebook, Instagram previews.
   - Twitter card tags.
   - Geo-location tags:
     - `geo.region`: `IN-TN`
     - `geo.placename`: `Uthukuli, Tirupur, Tamil Nadu, India`
     - `geo.position`: `11.1706027;77.4513681`

4. **Structured Data (JSON-LD)**:
   - Schema type: `FurnitureStore` and `WebSite`
   - Includes address, telephone, coordinates, logo, hero image, and social links.

5. **Google Search Console Steps**:
   1. Open [Google Search Console](https://search.google.com/search-console).
   2. Add property: `https://wuddartfurniture.in`.
   3. Verify ownership (via HTML tag, DNS record in GoDaddy, or file upload).
   4. Navigate to **Sitemaps** on the left menu.
   5. Enter `sitemap.xml` and click **Submit**.
   6. Use the **URL Inspection** tool on `https://wuddartfurniture.in/` and click **Request Indexing**.

6. **Google Business Profile**:
   Ensure your Google Business Profile name, address, phone number, and map pin match the website schema.
